## 2. Де ми НЕ відрізняємось (паритет або відставання)

- **Обробка документів (BOL/POD/rate con)** — у Truckstop вже працює Document Audit; у нас лише специфікація. Відставання, не відмінність.
- **Matching / рекомендації вантажів** — є в DAT (ML), Truckstop, Uber, Doft; наш — детермінована евристика. Паритет на кращий випадок.
- **Ліквідність** — DAT 700k+ постингів/день, у нас демо. Головний ризик будь-якого нового маркетплейсу.
- **Гарантія оплати / швидка оплата / факторинг** — є в DAT, Truckstop, Uber, Doft, Amazon Relay; у нас немає навіть у плані. Для прямої моделі (без брокера, який зазвичай гарантує оплату) це критичний пробіл.

## 3. Висновки для позиціонування

1. **Ніхто з великих не прибирає брокера.** DAT, Truckstop, Uber, Loadsmart — усі брокероцентричні. Прямо
   (без брокера) працюють лише Amazon Relay (один шипер) і Doft (маленький, цифри не підтверджені).
   Ніша «прямий маркетплейс для SMB-шиперів + AI» — реально вільна.
2. **AI-агенти вже стандарт — але на боці брокера.** Майже всі гроші йдуть на автоматизацію роботи брокера.
   «AI-агент переговорів» сам по собі не відрізняє; «AI, що робить брокера непотрібним для малого шипера» — відрізняє.
3. **Переговори всередині платформи замість телефонних ботів.** Doft-бот дзвонить брокерам, ті відповідають
   HappyRobot-ом. Структуровані bid/counter-offer між агентами через API — природна перевага прямої платформи.
4. **Довіра — головний біль ринку.** ~$725M збитків від крадіжок вантажів у 2025, ~69% фроду — подвійний
   брокеридж. Без брокера посередині подвійного брокериджу структурно менше — сильний маркетинговий аргумент.
   Але потрібні верифікація обох сторін + гарантія оплати/ескроу (саме це робить Relay і Uber надійними для перевізника).
   → **Аргумент на користь trust scoring як наступної AI-фічі.**
5. **Truckstop — найнебезпечніший за AI-роадмапом**: уже має live trust scoring і document audit.
6. **Монетизація з першого дня.** Convoy, Transfix, TruckSmarter — великі бази користувачів не врятували без
   транзакційної виручки. Референс: Doft — $0.99 за букінг + оплата AI-дзвінків за використання.
7. **Таймінг сприятливий**: обмеження CDL для нерезидентів (березень 2026, ~200k водіїв) і рекордні спот-ставки —
   шиперам важче знайти трак.

## 4. Що потрібно від тебе

- **Який саме «Loadhunt» ти мав на увазі?** Агент знайшов два варіанти:
  - **loadhunt.ai** (LoadHunt Corp.) — Chrome-розширення для диспетчерів поверх DAT/Truckstop (він у таблиці);
  - **theloadhunter.com** — крихітний анонімний freemium-борд для перевізників ($0–189), маркетить AI-інсайти по ставках і чернетки для переговорів.
- Які компанії лишити у фінальній таблиці для документації (пропоную: DAT, Truckstop, Uber Freight, Doft,
  Amazon Relay, Highway, HappyRobot + LoadHunt; решту — одним рядком «також на ринку»).
- Непідтверджені цифри (обсяги Doft, 125k перевізників Uber, мінімальний чек HappyRobot) — у доку піде з позначкою або без цих цифр.
